# LSFF input diff demo

A demo of how edits to the proposed `inputs/` files look in GitHub pull requests.
It supports the pre-read "How you will update LSFF input data".

Values that appear in the pre-read are copied from it. The rest are placeholders, made up so the files have a realistic size. Do not use them.

Open each pull request and read the **Files changed** tab.

| PR | What it shows |
|---|---|
| #1 | One value changes (wheat folate baseline concentration, 2.6 to 0), made in both `folate.csv` and `folate.yaml` |
| #2 | A new GF workbook: compliance changes for four vehicles, 14 rows cite a new decision |
| #3 | The same one-value change as #1, after the CSV is saved from Excel on Windows |
